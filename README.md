# สายธาร (Saitharn) — แชทบอท LINE ตรวจสอบพื้นที่อุทกภัย

โครงงานวิทยาการคอมพิวเตอร์ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร

แชทบอทผ่าน LINE ที่ให้ผู้ใช้ส่งตำแหน่งหรือพิมพ์ชื่อสถานที่ เพื่อตรวจสอบพื้นที่น้ำท่วมจากข้อมูลภาพถ่ายดาวเทียมและสถานีวัดน้ำ พร้อมพยากรณ์ฝน และตอบคำถามวิธีรับมือน้ำท่วมจากคู่มือของ ปภ. ด้วยเทคนิค RAG

> ผลลัพธ์ของระบบใช้เป็นข้อมูลประกอบการตัดสินใจเบื้องต้นเท่านั้น ไม่ใช่การประกาศเตือนภัยอย่างเป็นทางการ ควรติดตามประกาศของหน่วยงานทางการ หรือโทร 1784 (ปภ.)

## ความสามารถ

- **ตรวจพิกัดกับพื้นที่น้ำท่วม** ใช้ Point-in-Polygon เทียบกับข้อมูลน้ำท่วมจาก GISTDA (แดง = อยู่ในพื้นที่, เหลือง = อยู่ใกล้ภายใน 0.05°, ขาว = ไม่พบข้อมูล)
- **สถานีวัดน้ำใกล้ที่สุด** จาก Thaiwater (สสน.) คำนวณระยะด้วยสูตร Haversine แสดงสี แดง (ถึงระดับวิกฤต) / เหลือง (ต่ำกว่าวิกฤตไม่เกิน 0.5 ม.) / น้ำเงิน (ปกติ) / ขาว (ไม่มีข้อมูล)
- **พยากรณ์ฝนล่วงหน้า 24 ชั่วโมง** จากกรมอุตุนิยมวิทยา (TMD)
- **ถาม-ตอบวิธีรับมือน้ำท่วม (RAG)** ค้นจากคู่มือ ปภ. ใน Pinecone แล้วให้ Gemini เรียบเรียงคำตอบ
- **ข้อมูลย้อนหลัง** บันทึกรายวันลง SQLite ตอบได้ตั้งแต่วันที่เริ่มเก็บ (10 ต.ค. 2569)
- รองรับอินพุต: แชร์ตำแหน่ง, พิกัดที่พิมพ์เอง, ลิงก์ Google Maps (เต็ม/ย่อ), ชื่อสถานที่

## สถาปัตยกรรม

```
ผู้ใช้ (LINE) → LINE Messaging API → n8n (Webhook, ตรวจลายเซ็น HMAC-SHA256)
                                          ↓ POST /process
                                   FastAPI (process_api.py)
                     ┌──────────────┬──────────┴──────────┬───────────────┐
                  GISTDA        Thaiwater              TMD            RAG (Pinecone + Gemini)
               (พื้นที่น้ำท่วม)  (สถานีวัดน้ำ)       (พยากรณ์ฝน)       + SQLite (history.db)
```

## เทคโนโลยี

Python, FastAPI, n8n, LINE Messaging API, Google Gemini (สร้างคำตอบ + embedding), Pinecone, SQLite, Shapely

## วิธีติดตั้งและรัน

1. ติดตั้งแพ็กเกจ (Python 3.10 ขึ้นไป):
   ```
   pip install fastapi uvicorn requests python-dotenv shapely pypdf pinecone google-generativeai
   ```
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าของตัวเอง (ห้ามอัป `.env` ขึ้น GitHub)
3. เตรียมฐานความรู้ (ทำครั้งเดียว ต้องมีไฟล์ PDF คู่มือ ปภ.):
   ```
   python rag_ingest.py
   ```
4. รันเซิร์ฟเวอร์:
   ```
   python -m uvicorn process_api:app --port 8000
   ```
5. ตั้งค่า n8n ให้รับ Webhook จาก LINE และส่งต่อไปที่ `POST /process`
6. บันทึกข้อมูลรายวัน: `python daily_snapshot.py` (หรือให้ n8n เรียก `POST /snapshot` วันละครั้ง)

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ความหมาย |
|---|---|
| `GEMINI_API_KEY` | คีย์ Gemini |
| `GEMINI_MODEL` | โมเดลสร้างคำตอบ |
| `GEMINI_INTENT_MODEL` | โมเดลจำแนกเจตนา (ไม่ใส่ = ใช้ตัวเดียวกับ `GEMINI_MODEL`) |
| `GEMINI_FALLBACK_MODELS` | โมเดลสำรองคั่นด้วยจุลภาค ใช้เมื่อโควตาโมเดลหลักหมด |
| `PINECONE_API_KEY` | คีย์ Pinecone |
| `GISTDA_API_KEY` | คีย์ GISTDA Open API |
| `TMD_TOKEN` | โทเคน TMD Weather Forecast API |
| `RAG_MIN_SIMILARITY` | เกณฑ์ cosine similarity ขั้นต่ำ (ค่าเริ่มต้น 0.5) |
| `HISTORY_DB_PATH` | ที่เก็บไฟล์ `history.db` (ไม่ใส่ = ค่าเริ่มต้นของโปรแกรม) |
| `API_SECRET` | (ไม่บังคับ) รหัสให้ n8n ส่งใน Header `X-API-Secret` |

## ข้อจำกัด

- ข้อมูลย้อนหลังเริ่มสะสมตั้งแต่ 10 ต.ค. 2569 และสถิติดาวเทียมใช้ประกอบเท่านั้น ยืนยันเหตุการณ์จริงหรือความลึกของน้ำไม่ได้
- ภาพถ่ายดาวเทียมมีรอบเวลาถ่ายภาพ จึงอาจไม่ครอบคลุมน้ำท่วมฉับพลันหรือน้ำท่วมขังในเมือง
- Gemini แบบฟรีมีโควตาจำกัดต่อวันต่อโมเดล
- ระบบรันบนเครื่องของผู้พัฒนา ยังไม่ได้ติดตั้งบนบอร์ด Jetson

## แหล่งข้อมูล
